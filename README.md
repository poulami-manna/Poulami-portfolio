# 🌸 Poulami Manna — Personal Portfolio

A modern, elegant, and fully responsive personal portfolio website showcasing **Poulami Manna's** educational background, technical skills, projects, and professional journey.

Designed with a beautiful **Pink & Plum theme**, smooth animations, interactive elements, and a clean user interface for an engaging browsing experience across desktop, tablet, and mobile devices.


live :

## ✨ Features

- 🎨 **Modern UI/UX** — Clean, elegant, and professional design.
- 📱 **Fully Responsive** — Optimized for PC, tablet, and mobile devices.
- 🌙 **Dark & Light Mode** — Interactive theme toggle with dark mode enabled by default.
- 💗 **Pink & Plum Theme** — Beautiful gradients and aesthetic color combinations.
- ✨ **Animated Background** — Subtle animated effects and ambient glowing elements.
- 👩‍💻 **Interactive Hero Section** — Circular profile image with animated orbit effects.
- ⌨️ **Typing Animation** — Dynamic text animation showcasing professional roles.
- 🎓 **Education Journey** — Timeline-based academic milestones.
- 💡 **Skills Section** — Organized presentation of technical and professional skills.
- 🚀 **Projects Section** — Showcase of project work and concepts.
- 🎬 **Scroll Animations** — Smooth reveal effects while navigating the website.
- 📩 **Contact Section** — Contact form for visitor inquiries.
- 📄 **CV Included** — Downloadable CV files in PDF and DOCX formats.

## 🚀 How to Run Locally

Follow these steps to run the portfolio on your computer.

**Step 1: Clone the Repository**

```bash
git clone https://github.com/poulami-manna/YOUR-REPOSITORY-NAME.git
```

**Step 2: Open the Project Folder**

```bash
cd YOUR-REPOSITORY-NAME
```

**Step 3: Run the Website**

Open `index.html` in your preferred web browser.

**Recommended:** Use the Live Server extension in Visual Studio Code for a better development experience.

## 🎨 Customization Guide

You can easily customize the portfolio:

- **Content:** Edit `index.html`.
- **Colors & Design:** Edit `style.css`.
- **Animations & Interactions:** Edit `script.js`.
- **Profile Images:** Replace images inside the `assets/` folder while keeping the filenames unchanged, or update their paths in `index.html`.
- **CV:** Replace the PDF and DOCX files with updated versions.
