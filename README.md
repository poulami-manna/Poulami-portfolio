# Poulami Manna — Pink Edition Portfolio

A responsive portfolio inspired by the supplied Priyojit portfolio layout, recolored in premium pink/plum.

## Sections
Home, About, Education, Skills, Projects, Journey, Contact.

## Features
- Dark theme on first load, with a light/dark toggle
- Pink gradient accents replacing the blue palette
- Animated pink ambient background and star field
- Hero portrait, orbit rings and floating labels
- Repeating typing animation
- Scroll reveal, progress bar, responsive navigation
- Contact form opens the visitor's email app (mailto)

## Run
Extract the ZIP, open the folder in VS Code, and launch `index.html` with Live Server.

## Notes
The five project cards are proposed concepts, not claims of completed projects. The phone number is intentionally not displayed on the website. CV is included separately.
